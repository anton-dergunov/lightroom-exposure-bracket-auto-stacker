# Benchmark: finding bracketed sequences

How well time-based stacking finds bracketed sequences, compared with the plugin, on whole shoots. Generated by
`lua tools/benchmark.lua` from the fixtures in `tests/fixtures`; do not edit by hand.

**Time-based stacking** works like Lightroom's Auto-Stack by capture time: within a folder, photos sorted by
capture time share a stack while each is taken at most *gap* seconds after the previous one. *Seconds* compares
whole-second capture times, as the classic Auto-Stack by Capture Time does; *milliseconds* uses sub-second times,
as the Auto Stack added in Lightroom Classic 15 and Lightroom 9 (October 2025) does. Its other mode, grouping by
visual similarity, is an AI model that only Lightroom can run, so it is not included.

**Right** is the number of bracketed sequences that came out as exactly one stack. **Wrong stacks** are stacks
that are not exactly one sequence: sequences merged together or cut apart, or single shots stacked. The correct
sequences are the ones the camera recorded, which are checked against what was shot; the plugin reads the same
record, which is why it can match it.

## Summary

Time-based stacking needs a different gap for every shoot: brackets 0.1 s apart in daylight need a gap under
half a second, while long exposures at night need several seconds, and single shots taken in quick succession get
stacked with any gap long enough for either. The best gap for each shoot, chosen with hindsight:

| Shoot | Sequences | This plugin | Best time-based (gap) |
|---|---|---|---|
| Greenwich Park (A7C II, daylight, handheld) | 23 | 23 right, 0 wrong | 23 right, 0 wrong (milliseconds, gap 0.25 s) |
| Chiltern Open Air Museum (ZV-1) | 17 | 17 right, 0 wrong | 16 right, 0 wrong (milliseconds, gap 0.25 s) |
| A7C II test card | 28 | 28 right, 0 wrong | 20 right, 77 wrong (milliseconds, gap 0.5 s) |
| RX100 VII test card (RAW only) | 10 | 10 right, 0 wrong | 10 right, 4 wrong (seconds, gap 1 s) |
| ZV-E10 test card (RAW only) | 9 | 9 right, 0 wrong | 7 right, 2 wrong (seconds, gap 10 s) |
| Canon EOS 70D, three brackets 11-15 s apart | 3 | 3 right, 0 wrong | 3 right, 0 wrong (seconds, gap 1 s) |
| Canon EOS-1D Mark IV at night, long exposures | 2 | 2 right, 0 wrong | 2 right, 0 wrong (seconds, gap 5 s) |
